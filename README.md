# EduFlow Pro - Student Registration & Academic Management Hub

> A modern, professional Student Registration & Academic Management System web application built by integrating Java Internship Tasks 1, 2, and 3 into a single production-ready software project.

---

## 📚 Internship Task Mapping

This project combines all three internship deliverables:

| Task Milestone | Core Concepts Learned | EduFlow Pro Implementation |
| :--- | :--- | :--- |
| **Task 1: Fundamentals & Scanner** | Scanner user input, conditional logic, loops, Student model. | Interactive registration modal, CGPA calculations, real-time search & sorting filters. |
| **Task 2: Collections & Exceptions** | `ArrayList`, `HashMap`, `HashSet`, try-catch blocks, custom exceptions. | Live **Collections Inspector** & **Try-Catch Exception Playground** with real stack traces. |
| **Task 3: File I/O & GitHub** | `FileReader`, `FileWriter`, JSON/CSV export, Git & README. | Drag-and-drop file import, CSV/JSON export engine, embedded Git timeline, downloadable `.java` source. |

---

## 🌟 Application Features

- 🎨 **Glassmorphism UI & Dual Theme System**: Dark and Light theme toggle with vibrant gradient accents.
- ⚡ **Dual View Directory**: Seamlessly switch between dense Data Table and rich Grid Card views.
- 🔍 **Real-Time Instant Search**: Search by name, ID, email, major, or skill tag.
- 🛡️ **Custom Exception Playground**: Test exception handling (`DuplicateStudentException`, `InvalidGPAException`, `CourseCapacityExceededException`, `StudentNotFoundException`).
- 📁 **File Storage Engine**: Export & import database via JSON or CSV files with auto-save localStorage persistence.
- 💻 **Standalone Java Code Hub**: Built-in viewer and downloader for `StudentRegistrationSystem.java`.
